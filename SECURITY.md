# Security

Please do not open a public issue for a vulnerability that could affect users. Use GitHub's private vulnerability reporting for this repository when available, or contact the maintainer through the GitHub profile linked in the repository.

Include the affected version, reproduction steps, impact and any suggested mitigation. Do not include live credentials, private console data or personal information.

This repository is a UI component library and demo. It does not ship a backend, authentication service or device-control integration. Consumers are responsible for authorization, input validation, secrets and any real operational actions they connect to the components.
